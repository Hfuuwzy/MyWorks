# Asset Sources

## Homepage brand assets

| Source | Source properties | Runtime derivative | Use |
|---|---|---|---|
| `reference/images/我的名字.png` | `2172×724`; `1,014,067` bytes (~`990.3KB`); 24-bit RGB; no alpha | `public/images/brand/lonelyyang3-wordmark.png`; generated RGBA at unchanged `2172×724` | Main homepage brush wordmark |
| `reference/images/我的世界.png` | `1832×858`; `877,979` bytes (~`857.4KB`); 24-bit RGB; no alpha | `public/images/brand/lonelyyang3-myself-world.png`; generated RGBA at unchanged `1832×858` | Secondary bilingual brand artwork |

Both source images are user-provided/generated, and their rights and provenance were supplied by the user. They remain preserved and untouched. The two runtime files are deterministic transparent PNG derivatives generated by `scripts/generate-brand-assets.mjs` with local Sharp `0.34.5` / libvips `8.17.3`:

```text
node scripts/generate-brand-assets.mjs
node scripts/generate-brand-assets.mjs --check
```

For each RGB source pixel, the generator computes `base = min(r, g, b)` and `alpha = 255 - base`. When `alpha <= 3`, it writes transparent RGB0. Otherwise it writes straight, unpremultiplied RGBA with each foreground channel equal to `clamp(round((channel - base) * 255 / alpha), 0, 255)`. This removes the white canvas while retaining the original dimensions, pink bands, brown text, colors, and antialiased brush edges. The generator validates source metadata, output alpha/corners/pixel classes, white-background recomposition error, and exact runtime RGBA equality in `--check` mode.

No per-slice, cropped, dark-theme, or other raster variants may be created, except for the user-supplied homepage loading pieces below and their deterministic runtime derivatives. Slicing and the secondary crop remain CSS-only. No reference-site Logo, image, or other proprietary asset is copied, downloaded, or hotlinked.

`scripts/generate-home-intro-assets.mjs` copies all five loading-intro sources byte-for-byte to their matching runtime paths. Their existing alpha, `724×2172` dimensions, pre-positioned coordinates, and encoded PNG bytes remain unchanged; the generator does not transform, crop, resize, reposition, unmatte, re-encode, or otherwise process them.

The separate `reference/images/图标.png` source retains its transparent-generation path: bright neutral matte pixels are cleared first; remaining near-white edge pixels use `distance = max(255-r, 255-g, 255-b)` to receive linearly scaled alpha and per-channel white unmatting, while clearly non-white foreground pixels retain their original RGB and full opacity. All six source files are user-owned and remain untouched. No `deaimon.jp` image bytes are copied or hotlinked; the runtime files come solely from these user-supplied inputs.
