# 文档索引

## 当前权威文档

| 文档 | 受众 | 内容 |
|---|---|---|
| [`../README.md`](../README.md) | 使用者与新贡献者 | 安装、运行、路由、内容维护和改进顺序。 |

## 验证证据

`.superpowers/sdd/final-report.md` 是 `2026-07-15` 开发预览版本的内部验证快照，记录当时的测试、构建和审查结果。它是证据，不是持续维护的架构规范。

## 历史归档

以下目录保留了改版过程，供追溯决策和测试演进：

- `docs/superpowers/**`
- `.superpowers/sdd/task-*`
- `.superpowers/sdd/progress.md`

这些文件包含旧测试数量、旧路径名称、旧主图焦点值和已经停用的 Superpowers 执行流程。它们不是当前开发要求；实现新功能时不要从历史 checklist 恢复流程，而应读取当前代码、测试和上面的权威文档。

## 同步规则

发生以下变更时，应在同一次修改中同步文档：

- 路由、Content schema、locale 或主题流变化：更新 `ARCHITECTURE.md`。
- 视觉令牌、断点、组件合同或素材策略变化：更新 `DESIGN.md`。
- 安装命令、脚本、使用方式或发布状态变化：更新根 `README.md`。
- 历史实现文档通常不回写；必要时只增加归档说明。
